# Сборка сайта

Отвечай пользователю на русском (правило 0 в `SKILL.md` скилла `webik`).

1. Загрузи скилл `webik` (инструмент Skill; в установленном плагине он называется `webik:webik`), если он ещё не загружен в этой сессии.
2. Проверь Context7 по `SKILL.md` → «Context7 — обязательное условие для кода». Недоступен — остановись и не пиши код.
3. Прочитай `.webik/state.json`: нужен `design_artifact_url`. Если его нет, спроси ссылку на артефакт Claude Design.
4. Прочитай `references/build.md` из папки скилла и выполни этап по шагам. Он сам скажет, какие ещё справочники нужны.

Дополнительные указания: $ARGUMENTS
