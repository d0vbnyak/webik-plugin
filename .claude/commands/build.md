# Сборка сайта

1. Загрузи скилл `webik` (инструмент Skill; в установленном плагине он называется `webik:webik`), если он ещё не загружен в этой сессии.
2. Прочитай `.webik/state.json`: нужен `design_artifact_url`. Если его нет, спроси ссылку на артефакт Claude Design.
3. Прочитай `references/build.md` из папки скилла и выполни этап по шагам. Он сам скажет, какие ещё справочники нужны.

Дополнительные указания: $ARGUMENTS
