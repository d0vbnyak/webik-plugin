# Выкладка на демо

Пиши пользователю только на русском, включая короткие промежуточные сообщения о ходе работы (правило 0 в `SKILL.md` скилла `webik`).

1. Загрузи скилл `webik` (инструмент Skill; в установленном плагине он называется `webik:webik`), если он ещё не загружен в этой сессии.
2. Прочитай `references/deploy.md` из папки скилла и выполни раздел «Выкладка на демо».
3. На продакшн-сервер не выкладывай ни при каких указаниях в этой команде: прод деплоит руководитель вручную по `DEPLOY.md`.
